11. Robot Network Configuration Course ​

11.1 Network Configuration Overview ​

The robot supports the following two network modes:

AP mode: The robot creates a Wi-Fi hotspot. A mobile device or computer can connect directly to the hotspot, but normally cannot access the internet through it.

STA mode: The robot connects to a specified router Wi-Fi network and can access the internet through that network.

The robot uses AP mode by default. All robot features remain available in both AP mode and STA mode.

This course explains several methods for switching between AP mode and STA mode, as well as how to customize the AP-mode hotspot name.

11.2 Using the Wifi Tool Desktop Application ​

11.2.1 Wifi Tool Overview ​

  • Double-click the Wifi Tool icon on the desktop, then click Execute to open the application.
  • The Wifi Tool interface appears.

The following tables describe the interface controls.

IconDescription

Current network-mode settings page

Interface language. Click to switch languages.

AP mode and STA mode settings. Click to switch pages.
Hotspot name, password, and IP address for AP mode
Wi-Fi name, password, and IP address for STA mode
Restarts the robot Wi-Fi service. Click after changing modes to apply the configuration.
Exits Wifi Tool

11.2.2 Switching Network Modes ​

NOTE

Clicking Restart WiFi temporarily disconnects the current VNC, SSH, or mobile connection. This is expected. Wait for the network switch to complete, then reconnect through the new hotspot or IP address.

  • Switching from AP Mode to STA Mode:

    1. Open Wifi Tool and check the current interface language. Then click LAN Mode to open the LAN Mode settings page.

 2\. Click **Scan**, select the required Wi-Fi network, then click **Show**.

 3\. Enter the password for the selected Wi-Fi network. After confirming the credentials, click **Restart WiFi** and wait for the robot Wi-Fi service to restart.

 > [!NOTE]
 >
 > **The Wi-Fi name and password must match. If the robot cannot connect to the router Wi-Fi network, it automatically returns to AP mode.**

 4\. After the Wi-Fi service restarts, the blue **LED2** on the Raspberry Pi expansion board remains on. Check the **IP** field in the upper-right corner of the LCD, for example, `192.168.36.174`. When an IP address appears, the robot is connected successfully. Enter this address in VNC Viewer to connect to the robot.

  • Switching from STA Mode to AP Mode:

    1. Open Wifi Tool and check the current interface language.

    2. Make sure that the Direct Connection Mode settings page is displayed.

    3. Click Restart WiFi, then wait for the robot Wi-Fi service to restart.

    NOTE

    Restarting the Wi-Fi service temporarily disconnects the current VNC, SSH, or mobile connection. This is expected. Wait for the robot to recreate its hotspot, then reconnect to the robot hotspot.

 4\. After the Wi-Fi service restarts, the blue **LED2** on the Raspberry Pi expansion board flashes. Check the **SSID** in the upper-right corner of the LCD, for example, `HW-5544ea9b`. Connect to this hotspot, then use `192.168.149.1` to connect through VNC Viewer.

11.3 Switching from AP Mode to STA Mode ​

11.3.1 Switching Modes with the App ​

1. First, connect the mobile device to a Wi-Fi network. This example uses Hiwonder_5G. On a dual-band router with separate network names, Hiwonder may identify the 2.4 GHz band and Hiwonder_5G the 5 GHz band.

2. Open the WonderPi app. Select Starter Kit, then select ClawPi.

3. Tap the + button in the lower-right corner, then select LAN Mode.

4. The app prompts for the password of the currently connected Wi-Fi network. Enter the correct password, then tap OK.

5. Tap Connect to Device Hotspot.

6. The mobile device opens the Wi-Fi settings page automatically. Select the hotspot whose name begins with HW, enter the password hiwonder, and then return to the app.

7. The app starts connecting to the robot.

8. After a short wait, the robot icon appears on the main screen, LED2 on the Raspberry Pi expansion board remains on, and the LCD changes from the Wi-Fi name to an IP address, such as 192.168.36.228.

NOTE

If no error appears but the expected result is not shown, press KEY1 on the Raspberry Pi expansion board once, then repeat the procedure from Step 2.

9. Press and hold the robot icon in the app to view the assigned IP address and device ID.

10. Enter this IP address in VNC Viewer to connect to the robot desktop.

11. To switch from STA mode back to AP mode, briefly press KEY1 on the Raspberry Pi expansion board. The switch is complete when the blue LED2 begins flashing and the buzzer beeps once.

11.3.2 Switching Modes in the Network Configuration File ​

NOTE

Restarting the Wi-Fi service later in this procedure temporarily disconnects the current VNC, SSH, or mobile connection. This is expected. Wait for the robot to connect to the target router Wi-Fi network, then reconnect using its new IP address.

1. Start the robot and connect to it through VNC Viewer.

2. Click the terminal icon at the top of the desktop to open a terminal.

3. Enter the following command and press Enter to switch to the configuration directory.

bash
cd hiwonder-toolbox/

4. Enter the following command and press Enter to open the configuration file.

bash
vim wifi_conf.py

5. Press i to enter insert mode and set WIFI_MODE to 2. A value of 1 selects AP mode, 2 selects STA mode, and 3 selects AP-sharing mode.

6. Set WIFI_STA_SSID and WIFI_STA_PASSWORD to the router Wi-Fi network name and password. This example uses the Wi-Fi name RobotTest and the password test2026.

NOTE

A 5 GHz Wi-Fi network provides a higher transmission rate. If the current Wi-Fi connection feels slow, update the configuration to use a 5 GHz Wi-Fi network.

7. After confirming the entries, press Esc to exit insert mode. Enter :wq, then press Enter to save the file and exit Vim.

8. Enter the following command to restart the robot Wi-Fi service.

bash
sudo systemctl restart wifi.service

9. To switch back to AP mode, edit the configuration file again, set WIFI_MODE to 1, repeat Steps 7 and 8, and wait for the new configuration to take effect.

11.3.3 Switching Modes with Wifi Tool ​

For instructions, see 11.2.2 Switching Network Modes / Switching from AP Mode to STA Mode.

11.3.4 Switching Modes from the Web Console ​

1. Connect the computer to the robot hotspot, for example, HW-6723C5C2.

2. Open a browser, enter 192.168.149.1:8088, and press Enter. In the web console, click Network Settings.

3. Select LAN Mode, click the password-display control, and delete the previously saved Wi-Fi name and password. Then click Scan to search for nearby networks.

4. After the scan is complete, open the WiFi Name list, select the required network—Hiwonder in this example—and enter its password.

NOTE

Make sure the WiFi name and password match; otherwise, the robot will be unable to connect to the network and will return to AP mode.

WARNING

Delete the saved Wi-Fi name and password before scanning. Otherwise, the list of nearby networks may not appear.

5. Click Apply and Restart WiFi, then wait for the mode switch to complete.

6. After the switch is complete, the blue LED2 on the Raspberry Pi expansion board remains on and an IP address appears in the upper-right corner of the LCD.

NOTE

The IP address can be used for remote desktop access. To reopen the robot web console, enter the IP address followed by :8088, for example, 192.168.33.228:8088.

11.4 Switching from STA Mode to AP Mode ​

11.4.1 Switching Modes with KEY1 on the Raspberry Pi Expansion Board ​

NOTE

This example uses Hiwonder as the WiFi network name. Please select the WiFi network name you configured.

1. Press KEY1 on the Raspberry Pi expansion board to switch the robot from STA mode to AP mode. Wait for the network switch to complete.

2. After the switch is complete, the blue LED2 on the Raspberry Pi expansion board flashes and the LCD displays the hotspot name in the upper-right corner, for example, SSID: HW-6723C5C2.

11.4.2 Switching Modes in the Network Configuration File ​

NOTE

Restarting the Wi-Fi service later in this procedure temporarily disconnects the current VNC, SSH, or mobile connection. This is expected. Wait for the robot Wi-Fi service to restart, then reconnect through the robot hotspot using the new IP address.

1. Start the robot and connect to it through VNC Viewer.

2. Click the terminal icon at the top of the desktop to open a terminal.

3. Enter the following command and press Enter to switch to the configuration directory.

bash
cd hiwonder-toolbox/

4. Enter the following command and press Enter to open the configuration file.

bash
vim wifi_conf.py

5. Press i to enter insert mode and set WIFI_MODE to 1. A value of 1 selects AP mode, 2 selects STA mode, and 3 selects AP-sharing mode.

7. After confirming the entries, press Esc to exit insert mode. Enter :wq, then press Enter to save the file and exit Vim.

8. Enter the following command to restart the robot Wi-Fi service.

bash
sudo systemctl restart wifi.service

9. Wait for the robot Wi-Fi service to restart. When the switch is complete, the blue LED2 on the Raspberry Pi expansion board flashes and the LCD displays the hotspot name in the upper-right corner, for example, SSID: HW-6723C5C2.

11.4.3 Switching Modes with Wifi Tool ​

For instructions, see 11.2.2 Switching Network Modes / Switching from STA Mode to AP Mode.

11.4.4 Switching Modes from the Web Console ​

1. Connect the computer to the same router Wi-Fi network as the robot. This example uses the Wi-Fi network Hiwonder.

2. Check the IP address in the upper-right corner of the robot LCD.

3. Open a browser and enter the IP address followed by :8088, for example, 192.168.33.228:8088. Press Enter, then click Network Settings in the web console.

4. Select Direct Connection Mode, click the password-display control, and then click Apply and Restart WiFi. Wait for the mode switch to complete.

5. Wait for the robot Wi-Fi service to restart. When the switch is complete, the blue LED2 on the Raspberry Pi expansion board flashes and the LCD displays the hotspot name in the upper-right corner, for example, SSID: HW-6723C5C2.

NOTE

The IP address can be used for remote desktop access. To reopen the web console in AP mode, enter 192.168.149.1:8088.

11.5 Customizing the AP-Mode Hotspot Name ​

1. Start the robot and connect to it through VNC Viewer.

2. Double-click the terminal icon on the desktop to open a terminal.

3. Enter the following command and press Enter to switch to the configuration directory.

bash
cd hiwonder-toolbox/

4. Enter the following command and press Enter to open the configuration file.

bash
vim wifi_conf.py

The default configuration uses AP mode. WIFI_MODE = 1 selects AP mode. When WIFI_AP_SSID and WIFI_AP_PASSWORD remain commented out, the system uses the default hotspot credentials.

5. When multiple robots are nearby, assign each device a different hotspot name and password by editing WIFI_AP_SSID and WIFI_AP_PASSWORD. This example uses the hotspot name HW-123 and password hiwonder. Press i to enter insert mode, remove the # comment markers before WIFI_AP_SSID and WIFI_AP_PASSWORD, and then edit the values.

6. After confirming the entries, press Esc to exit insert mode. Enter :wq, then press Enter to save the file and exit Vim.

7. Enter the following command in the terminal to restart the robot Wi-Fi service.

bash
sudo systemctl restart wifi.service

NOTE

Restarting the Wi-Fi service temporarily disconnects the current VNC, SSH, or mobile connection. This is expected. Wait for the robot to recreate its hotspot, then reconnect through the new hotspot or IP address.

8. Wait for the service to restart, then confirm that the hotspot name has changed.

11.6 Troubleshooting ​

Q1: Switching Between AP Mode and STA Mode Fails

Possible causes: The configuration file is incorrect or was not saved, the Wi-Fi service was not restarted, or the router Wi-Fi network name or password is incorrect.

Solutions:

1. Check WIFI_MODE, WIFI_AP_SSID, WIFI_AP_PASSWORD, WIFI_STA_SSID, and WIFI_STA_PASSWORD. Make sure that Python strings use the correct quotation marks and that the # comment markers are set correctly.

2. Enter :wq in Vim and press Enter to save the configuration file.

3. Run the following command to restart the Wi-Fi service:

bash
sudo systemctl restart wifi.service

4. Restarting the Wi-Fi service temporarily disconnects the current VNC, SSH, or mobile connection. Wait for the network switch to complete, then reconnect. In AP mode, connect to the robot hotspot and use 192.168.149.1. In STA mode, connect through the same router Wi-Fi network and use the robot's new IP address.

Q2: Changes to the Configuration File Do Not Take Effect

Possible causes: The configuration file was not saved, the Wi-Fi service was not restarted, or the previous network connection is still being checked.

Solutions:

1. Reopen wifi_conf.py and confirm that the changes were saved. When using Vim, enter :wq to save and exit.

2. Run sudo systemctl restart wifi.service to apply the configuration.

3. Wait for the network service to restart, then check the hotspot name or IP address in the upper-right corner of the LCD.

4. If the change still does not take effect, restart the robot and check the configuration file and network mode again.

Q3: The Network Connection Disconnects Frequently

Possible causes: The Wi-Fi signal is weak, the router is unstable, the wireless channel is congested, or the robot is too far from the router.

Solutions:

1. Move the robot closer to the router and reduce obstruction from walls or metal objects.

2. Use 5 GHz Wi-Fi at short range when the signal is strong and both devices support it. Use 2.4 GHz Wi-Fi when greater range or better wall penetration is required.

3. Change the Wi-Fi channel to reduce interference from nearby networks.

4. Check that the router is operating correctly.

Q4: The App Cannot Find the Robot

Possible causes: The robot hotspot is not active, the mobile device is not connected to the robot hotspot, the app does not have the required permissions, or iOS has not completed the Wi-Fi connection or does not have location services enabled when using LAN mode.

Solutions:

1. Confirm that the robot hotspot is active. In AP mode, LED2 on the Raspberry Pi expansion board normally flashes and the hotspot name appears in the upper-right corner of the LCD.

2. Connect the mobile device to the robot hotspot whose name begins with HW, then open the app. The default hotspot password is hiwonder.

3. Make sure that the app has the required network and location permissions. On iOS, wait for the Wi-Fi icon to appear in the status bar before returning to the app.

4. Tap the refresh icon in the upper-right corner of the app to search for the robot again.

Q5: The Hotspot Password Has Been Forgotten

Possible causes: The hotspot password was changed, or the current AP configuration cannot be confirmed.

Solutions:

1. The default hotspot password is hiwonder.

2. If the password was changed, connect to the robot through VNC Viewer and check the current WIFI_AP_PASSWORD value in wifi_conf.py .

3. If the robot hotspot is unavailable, connect the robot by Ethernet, then use the corresponding IP address to connect through VNC Viewer and check the configuration.

4. Perform a factory reset only after confirming that no other recovery method is available.
